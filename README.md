# Birthday Air Hockey

Air hockey against the computer, in the browser. First to ten goals wins.

**Play it:** https://dprol.github.io/air-hockey/

Move your paddle with the mouse, or with a finger on a phone, where the rink turns upright. You cannot cross the centre line. Win, and there is a party.

## Run it locally

The whole game is one file, `index.html`, with no build step and no dependencies. Open it in a browser, or serve the folder:

```
python3 -m http.server 8000
```
